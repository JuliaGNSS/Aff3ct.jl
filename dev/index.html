Aff3ct.jl

Julia bindings for the AFF3CT Forward Error Correction (FEC) library.

Supported Codes

  • Polar codes — Encoder, Successive Cancellation (SC) decoder, SC List (SCL) decoder, frozen-bit generation via Gaussian Approximation (GA) or 5G-NR standard tables
  • Turbo codes — Encoder/decoder with LTE interleaver and BCJR (Bahl-Cocke-Jelinek-Raviv) Soft-Input Soft-Output (SISO) component decoders
  • LDPC codes — Low-Density Parity-Check encoder and Belief Propagation (BP) decoder using Sum-Product Algorithm (SPA) flooding
  • RSC + Viterbi — Recursive Systematic Convolutional encoder with Viterbi (SIHO) decoder
  • Feedforward convolutional + Viterbi — Non-systematic convolutional encoder (e.g. Galileo E1B) with Viterbi (SIHO) decoder

Quick Example

using Aff3ct

# Polar encode/decode
K, N = 128, 256
fb = generate_frozen_bits_ga(K, N; design_snr=2.0)
enc = PolarEncoder(K, N, fb)
dec = PolarSCLDecoder(K, N, 8, fb)

U_K = Int32.(rand(Bool, K))
X_N = encode(enc, U_K)

# BPSK + AWGN channel
sigma = 0.5f0
Y_N = Float32[1f0 - 2f0*x for x in X_N] .+ sigma .* randn(Float32, N)
llrs = 2f0 .* Y_N ./ sigma^2

V_K = decode(dec, llrs)

Common API

All encoders share a single encode / encode! entry point that dispatches on the concrete subtype of AbstractEncoder; likewise decode / decode! on AbstractDecoder.

Aff3ct.AbstractEncoder — Type
AbstractEncoder

Supertype for all encoder objects (PolarEncoder, LDPCEncoder, TurboEncoder, RSCEncoder, ConvEncoder). Concrete subtypes carry a ccall handle plus K/N fields, and dispatch the generic encode and encode! entry points.

source
Aff3ct.AbstractDecoder — Type
AbstractDecoder

Supertype for all decoder objects (PolarSCDecoder, PolarSCLDecoder, LDPCBPDecoder, TurboDecoder, ViterbiDecoder, ConvViterbiDecoder). Concrete subtypes dispatch the generic decode and decode! entry points.

Aff3ct.encode — Function
encode(enc, U_K) -> X_N

Encode information bits U_K (length enc.K) and return a freshly allocated codeword X_N (length enc.N). Accepts Int32, Bool, or any AbstractVector{<:Integer}; non-Int32 inputs are converted.

source
Aff3ct.encode! — Function
encode!(X_N, enc, U_K) -> X_N

Encode U_K (length enc.K) into the preallocated buffer X_N (length enc.N). Returns X_N for chaining. Allocation-free; preferred inside tight Monte-Carlo loops.

source
Aff3ct.decode — Function
decode(dec, Y_N) -> V_K

Decode LLRs Y_N (length dec.N) and return a freshly allocated information-bit vector V_K (length dec.K). Accepts Float32 or any AbstractVector{<:AbstractFloat}; non-Float32 inputs are converted.

source
Aff3ct.decode! — Function
decode!(V_K, dec, Y_N) -> V_K

Decode the LLR vector Y_N (length dec.N) into the preallocated buffer V_K (length dec.K). Returns V_K. Allocation-free.
